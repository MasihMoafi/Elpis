# ELPIS-UI-20260905-01 — restored context display

Engineering verification, not a provider experiment or visual acceptance.
This report covers offline replay of previously measured context data. Private
archives and raw captures remain outside the repository; this is an aggregate
method/check record, not a self-contained reproduction package.

## Method

Replay one saved conversation in an isolated offline profile using an
unreachable loopback provider and no new external inference. Compare the empty
state, resumed Ledger, and `/context` output against the archived token-count
record. Explicit RGB markers are checked from the captured ANSI data; rendered
cell replays are not native desktop screenshots.

## Observations

- Before a snapshot, Ledger reports usage unavailable and draws no false zero bar.
- After resume, both views show 9,805 / 258,400 = 3.7945%, rounded to 3.8% in
  `/context` and 4% in Ledger.
- All eight category values and RGB markers match. Scaled category estimates sum
  exactly to 9,805; they are reconciled estimates, not provider-measured counts.
- Bar occupancy is 4/96 cells in `/context` and 2/49 in Ledger, correctly
  rounded from the same full-window fraction.
- Deliberate count, color, and occupied-cell corruptions fail the comparison.
- The replay preserves the recorded Smart Prune outcome, while the separate
  display follow-up for an explicit Smart Prune summary remains unverified.

## Limits and follow-up

Startup included manual onboarding and is not a startup-speed measurement.
Native terminal visual acceptance remains open. The replay does not establish
provider accounting, generalized quality, causal savings, or a new runtime
semantics claim. A possible provenance issue in an earlier failed-loopback
replay was not established by the available persisted events and was not changed.

Private raw evidence contains the captures, renderer, launcher, and verification
inputs. It is deliberately not identified by workstation path, process/session
identifier, commit reference, or hash in this public report. Preserve the
relative report links when reusing this result.
