# ELPIS-BRAND-20260905-01 — Elpis copper accent

Engineering visual verification; not a provider experiment or user acceptance.
This record summarizes focused style checks, guarded recovery, and offline
rendered checks. Private execution journals and raw captures remain outside the
repository and are not public reproducibility artifacts.

## Contract

- Soft copper `#e6a28c` on dark terminals and deep copper `#974b35` on light ones.
- Shared identity color covers the composer, Ledger frame/headings, and
  `/context` section headings. Data, category, status, startup palettes, and
  neutral model text remain unchanged.
- No context arithmetic, pruning, filesystem/network behavior, or dashboard changes.

The primary contrast is 8.38:1 against `#181818` and 5.87:1 against `#faf8f5`.
All six brand/secondary/informational values exceed 4.5:1 against their
corresponding reference background. Arbitrary themes, ANSI fallback, and dimmed
text are outside this claim.

## Aggregate verification

Eighty focused Rust checks passed: 12 style/status-style, 45 Ledger, and 23
context-usage checks. The checks include identity/frame rendering and RGB
marker comparisons. Three deliberate count/color/bar corruption controls failed
as intended. Rendered cell replays were visually inspected; they are not native
desktop screenshots, so terminal font metrics and window chrome remain outside
the evidence.

The optimized recovery completed in 2,006 seconds outer time with 25 cooling
holds; sampled inner peak was 76 C and outer peak was 82 C. This establishes
recovery under the guarded build procedure, not a below-80 C whole-machine
guarantee or a representative warm-edit benchmark. Installation took 0.21 s.
User-visible terminal acceptance remains a separate gate.

The thermal wrapper's fake-Cargo suite covered pause/resume without restarting,
hard-limit holds, sensor loss, cancellation, and leader-exit cleanup. These are
mechanism checks, not proof of system-wide thermal control.
