# Sol/Luna grading recovery — 25 October 2026

**Both task pairs tied.** Four new runs used GPT-6 Sol High and GPT-6 Luna Low
pruning through the saved ChatGPT login.

| Official task | Pruning OFF | Pruning ON | Verified ON admissions |

One means pass; zero means fail. Web failed with HTTP 404; SQLite passed all three
checks in each arm. Earlier regex scored 1/1 separately, with its ON audit unknown.
No difference in task success was observed on these two tasks. This is a small
exploratory comparison.

Collection took **45 minutes after setup**, including recovery. Both arms used
two CPUs, 4 GiB RAM, no swap, and the unchanged resource guard. Agent and verifier
limits matched the official 900-second defaults. All agents exited normally;
seven admissions have complete receipts.

Web ON's download timeout is retained. Its grader resumed without a model retry;
previously running nginx/sshd services restarted from unchanged configuration.
Official test hashes matched. The cache serves the exact public installer and
uv 0.7.13 archive; task-test curl calls use the original binary. Web bootstrap
routing differs; both SQLite arms used the complete cache.

**Sol alone used 72.4% more tokens ON.** Its uncached input rose from 58,935 to
69,606 (+18.1%); output rose from 12,821 to 18,334 (+43.0%). Cached input was
631,936 OFF and 1,125,248 ON. These three categories sum to the Sol totals above.
Totals count input plus output, including cached input once. Reasoning is already
part of output. Including Luna, ON used **77.7% more tokens** overall: 138.4% more
on web-server and 24.2% more on SQLite.
These are observed usage totals from different agent rollouts. Shared cache state
was not isolated. **Dollar cost was not measured**, so no monetary savings claim
follows from the saved-login runs.

For planning: the [Terminal-Bench 2.0 paper](https://arxiv.org/html/2601.11868v1#S3)
uses 89 tasks and at least five repetitions per agent/model. ON/OFF means 178 runs
per sweep, or 890 with five repetitions. Assuming ten minutes each gives roughly
30 or 150 serial hours, before quota delays. Local Docker works; the
[Kaggle workflow](https://www.kaggle.com/docs/benchmarks) is not integrated with
this saved-login harness. No full-suite run starts automatically.
