Install Elpis.

Ubuntu and Debian install both Debian packages from the release. Fedora, Arch, Omarchy and any other Linux run the AppImage; Arch and Omarchy can also build the native package. The script installs the terminal app only; read it before you run it.

Download v0.5.1 ↗ 
Ubuntu, Debian
sudo apt install ./elpis_0.5.1_amd64.deb ./elpis-desktop_0.5.1_amd64.deb && elpis-app
Fedora, Arch, Omarchy, any Linux
chmod +x Elpis-0.5.1-x86_64.AppImage && ./Elpis-0.5.1-x86_64.AppImage
Arch, Omarchy (native package)
git clone https://github.com/MasihMoafi/Elpis && cd Elpis/packaging/aur/elpis-bin && makepkg -si
Terminal app only
curl -fsSL https://raw.githubusercontent.com/MasihMoafi/Elpis/v0.5.1/scripts/install-elpis.sh | bash && ~/.local/bin/elpis
