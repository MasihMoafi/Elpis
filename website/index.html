The desktop app

One chat.
Your theme.

The desktop app runs the same engine as the terminal app and shares its state folder. Chat with GPT, Claude and Gemini models on your ChatGPT or Claude subscription or an API key. Pick Elpis, Paper, Midnight or Plum, each in light and dark, or build your own in Settings.

v0.5.1 · Linux x86_64

Install Elpis.

The script installs the terminal app. For the desktop app on Ubuntu or Debian, install both Debian packages from the release together; on Fedora, Arch, Omarchy or any other Linux, run the AppImage. Inspect the source before running the script.

Download v0.5.1 ↗ 
curl -fsSL https://raw.githubusercontent.com/MasihMoafi/Elpis/v0.5.1/scripts/install-elpis.sh | bash && ~/.local/bin/elpis
sudo apt install ./elpis_0.5.1_amd64.deb ./elpis-desktop_0.5.1_amd64.deb && elpis-app
chmod +x Elpis-0.5.1-x86_64.AppImage && ./Elpis-0.5.1-x86_64.AppImage
