Context engineering

            
Compress the noise.
Keep the evidence.

          

          

            Terminal outputs and file searches shouldn't penalize every future turn. Elpis filters and distills tool output while preserving raw audit logs on disk, reducing peak context by 47–65%.
          

        


        

          

            Layer 01
            
RTK Shell Compaction

            
Compacts shell command output before it reaches the model, stripping ANSI noise and trimming redundant grep and compiler output.

            Before model ingestion
          

          

            Layer 02
            
Deterministic Safety Cap

            
Strict ceiling bounds exceptionally large tool results, preventing single accidental command outputs from blowing the budget.

            Hard budget guardrail
          

          

            Layer 03
            
Ace Distillation (/prune)

            
Rewrites eligible tool evidence into dense, structured findings with audit pointers, triggered at 30% pressure or on demand.

            47–65% peak context reclaimed

Deterministic multi-agent coordination

            
Directed work graphs.
Zero race conditions.

          

          

            When tasks run across subagents, they must not overwrite each other's files, spin in cyclic dependency loops, or declare victory without evidence. Elpis enforces deterministic DAG boundaries.
          

        


        

          

            
01

            
Kahn's Topological Validation

            
Every coordinated workflow is parsed into a Directed Acyclic Graph. Cycles, bad dependencies, and invalid roles are rejected before any worker agent is created.

            Pre-execution validation
          

          

            
02

            
Write-Boundary Isolation

            
Subagents receive declared write path prefixes. When tasks touch overlapping directories, Elpis automatically serializes execution to prevent destructive git conflicts.

            Write-collision prevention
          

          

            
03

            
Evidence Verification Gate

            
Downstream tasks remain locked until the assigned worker proves completion against explicit acceptance criteria with passing tests and verified git diffs.

            Audited task release
          

        

      


      

        

          

            
Technical architecture

            
Engineered in Rust.
Zero runtime overhead.

          

          

            Elpis runs as a native terminal layer built on the Codex-rs foundation. It manages context admission, token budgets, execution sandboxes, and cryptographic checkpoint evidence with sub-millisecond responsiveness.
          

        


        

          

            Core runtime
            
Compiled Rust Kernel

            
Sub-millisecond input loop built with Ratatui and Crossterm. Memory footprint stays under 14MB resident with zero telemetry or background tracking daemons.

            
    
              
  • Binary Pure local execution (macOS, Linux)
    • 
              
  • TUI 24-bit TrueColor buffer with zero flicker
    • 
              
  • Privacy Zero analytics, no third-party telemetry
    • 
            

          


          

            Admission engine
            
Deterministic Pruning & Metering

            
Prunes stale intermediate outputs and meters exact model-window usage before dispatching requests. Admitted rules, user-maintained memory (AGENTS.md), and checkpoints remain auditable.

            
    
              
  • Pruning Discards stale tool traces while retaining conclusions
    • 
              
  • Budgeting Real-time token consumption estimates
    • 
              
  • Drift Prevents loss of scope during long-running sessions
    • 
            

          


          

            Runtime neutrality
            
Swappable Provider Backends

            
Handoff execution across hosted models and local inference without discarding working constraints or recreating tool permissions.

            
    
              
  • Hosted OpenAI API, Anthropic Claude native endpoints
    • 
              
  • Local Ollama, vLLM, and OpenAI-compatible runners
    • 
              
  • Continuity Shared task thread survives model failure or swap
    • 
            

          


          

            State persistence
            
Verifiable Checkpointing

            
Clean continuation via structured GOAL.md and ES.md artifacts. Workspace file modifications, command outputs, and evidence remain attached.

            
    
              
  • Continuity Dual-mode: exact resume or lean continuation
    • 
              
  • Ledger File touch logs and execution command audits
    • 
              
  • Portability Plain markdown state readable by human or agent
