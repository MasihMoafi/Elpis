# Release state

The maintainer accepted the installed v0.2.0 candidate on 2026-09-05 and authorized
publication after privacy review and the hosted release gates. The public source
snapshot preserves the accepted runtime source; private execution journals and raw
session archives are retained locally, not included in this repository snapshot.

See [release notes](.github/RELEASE_NOTES.md), the [technical guide](docs/GUIDE.md),
and the [experiment log](docs/evals/EXPERIMENT_LOG.md) for public behavior and evidence.
The technical preprint remains a draft: ON-only observations do not establish
controlled cache non-regression, net cost savings, or general task quality.
