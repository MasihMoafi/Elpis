# Code of conduct

Elpis follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). It applies in the issues, pull requests and discussions of this repository, and wherever you represent the project.

To report unacceptable behaviour, write to the maintainer at hi@masihmoafi.com. Reports are read in confidence, and the maintainer acts on them as the Covenant's enforcement guidelines describe.
